# Difflib TS

A port of qiao/difflib to Typescript to be used in node or the browser

## Installation

Configure npm to use GitHub Packages for the `@mailmangroup` scope and authenticate with a classic personal access token that has `read:packages` permission:

```ini
@mailmangroup:registry=https://npm.pkg.github.com
//npm.pkg.github.com/:_authToken=${GITHUB_PACKAGES_TOKEN}
```

Then install the package:

```sh
npm install @mailmangroup/difflib-ts
```
